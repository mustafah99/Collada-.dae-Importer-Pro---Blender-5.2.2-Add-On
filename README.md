# Collada-.dae-Importer-Pro---Blender-5.2.2-Add-On
An add-on for Blender 5.2.2 allowing you to import .dae files onto Blender which was otherwise removed from Blender 5.0 when it was released. This add-on also imports textures and applies them correctly to the model from wherever the .dae file has pointed to.

It was made using GLM-5.3-Flash as an alternative to the Blender-v5-DAE-Importer-Add-on by ekztal since I found it to no longer work as intended with this specific version of Blender.

It's free for you to use, look at or modify as needed. The license is CC0 1.0 Universal.

Download the add-on .zip file through the "Releases" tab and install through Blender by going to Files > Preferences > Add-ons > Install from disk > then select the .zip file and enable it.
