# Collada-.dae-Importer-Pro---Blender-5.2.2-Add-On
An add-on for Blender 5.2.2 allowing you to import .dae files onto Blender which was otherwise removed from Blender 5.0 when it was released. This add-on also imports textures and applies them correctly to the model from wherever the .dae file has pointed to.
